# Daylight Todo

A small React Todo app with a demo login and browser-based todo storage.

## Run locally

```sh
npm install
npm run dev
```

Sign in with `student@example.com` and `password123`. Todos persist in browser
localStorage; the demo login lasts for the current browser session.

## Features

- Separate login and Todo pages with credential validation
- Add, complete, delete, and filter todos
- Remaining-task count and responsive layout
- No backend required
